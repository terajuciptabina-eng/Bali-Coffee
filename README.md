# BaLi Coffee Web App

Standalone, mobile-first static prototype for BaLi Coffee, using the supplied brand reference image and two-page menu PDF as the visual/content basis.

## Current features
- Responsive landing page and BaLi Coffee brand styling
- Search and menu category filters
- 56 drinks and listed prices based on the supplied menu
- Basic customization UI, shopping bag and subtotal
- Mobile-friendly layout

## Not connected yet
No backend, real ordering, payment, user accounts, live inventory, loyalty database, store locator or admin dashboard. Customization choices are prototype UI only; confirm available choices and any extra charges before production. Drink illustrations are CSS placeholders rather than official product photography. Verify all prices before launch.
